# 🛍️ Chandni Chowk

A modern **React-based E-Commerce Web Application** inspired by the vibrant shopping experience of Chandni Chowk. This project allows users to browse products by category, view product details, and manage their shopping cart through a clean and responsive interface.

---

## 🚀 Features

-  Home Page
-  Men's Collection
-  Women's Collection
-  Kids Collection
-  Electronics
-  Groceries
-  Browse Products
-  Product Ratings
-  Discount Price Display
-  Add to Cart
-  Remove from Cart
-  Cart Persistence using Local Storage
-  API Integration using DummyJSON
-  Add to favrouite

---

## ⚙️ Installation:-

### Clone the Repository

```bash
git clone https://github.com/shivamdevraj02/ChandniChowk.git
```

### Navigate to the Project

```bash
cd ChandniChowk
```

---

### Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

---

### Backend Setup

```bash
cd Backend
npm install
npm start
```

---

## 🌐 API Used:-

This project uses the **DummyJSON API** for fetching product data.

```
https://dummyjson.com/products
```
